# 챙길까? (PackCast)

> 강수확률 60%, 그래서 우산 챙겨요 말아요? 82번 시뮬레이션으로 대신 판단해 드려요.

외출하는 시간(출발~귀가) 동안의 날씨를 **82개의 앙상블 예보 시나리오**(ECMWF 51개 + GFS 31개)로 확인해서,
겉옷·우산·눈 대비·장갑·마스크를 **얼마나 확실하게** 챙겨야 하는지 알려주는 웹앱입니다.

## 무엇이 다른가요?
- 일반 예보: 시간대별 강수확률, 기온 숫자 하나
- 챙길까?: **외출하는 동안 한 번이라도** 비·눈을 만날 확률, 기온의 **범위와 확신도**(확실 / 아마도 / 애매함), 그리고 챙길 것

## 판단 방법
1. Open-Meteo 앙상블 API에서 82개 시나리오의 시간별 예보를 받습니다.
2. 사용자의 외출 시간대만 잘라냅니다.
3. 시나리오마다 비·눈 여부, 최저 체감온도, 강풍, 결빙 가능성을 판단합니다.
4. 결과를 세어 다수 의견 비율로 확신도를 정합니다. (85% 이상 확실, 65% 이상 아마도, 그 아래 애매함)

판단 기준값은 `app.js` 맨 위 `RULES`에 모여 있고, 수집한 예보와 실제 관측을 비교해 조정합니다.

## 구성
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 화면 |
| `app.js` | 예보 불러오기, 판단 규칙, 화면 그리기 |
| `cities.js` | 도시 목록 |
| `collector/save_forecast.py` | 정확도 검증용 예보 저장 (20개 도시) |
| `.github/workflows/collect.yml` | 매일 오전 6시 자동 저장 |

## 데이터
- 날씨: [Open-Meteo](https://open-meteo.com/) 앙상블 API, 대기질 API (비상업 무료)
- 개인정보를 수집하지 않으며, 선택한 도시와 시간은 브라우저에만 저장됩니다.
